# Password Strength Checker System using Machine Learning

This system is a web-based password strength checker that classifies user passwords as Weak, Medium, or Strong using a Machine Learning model.

## Technologies Used

- Python
- Flask
- Scikit-learn
- HTML/CSS
- Docker
- Kubernetes

## System Features

- Password input
- Strength classification
- Password improvement suggestions
- Machine Learning prediction
- Docker containerization
- Kubernetes deployment
- ConfigMap and Secret usage
- Multiple replicas for scalability
